# Supply Chain Analytics using SQL (Snowflake Schema)
This project demonstrates an end-to-end SQL-based supply chain analytics solution. The database is designed using a Snowflake Schema to support analytical queries.


## Key Features
- Snowflake dimensional modeling
- Fact and dimension tables
- Advanced SQL queries (joins, subqueries, window functions)
- Business-driven insights (revenue, demand, supplier analysis)

## Technologies Used
- SQL (MySQL compatible)
- Dimensional Modeling
- Snowflake Schema
- Retail Supply Chain Dataset

## Business Insights
- Identified high-demand products
- Analyzed supplier revenue contribution
- Calculated customer lifetime value
- Evaluated country-wise dependency for supply
